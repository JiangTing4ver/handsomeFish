> 接进挂件、并把信息结构化落盘。
>

## 一、你只需要给我这几栏

每张图一段，**复制这个模板填**（方括号里是给我的判断依据，不用你写解释）：

```text
文件:     _refs/小绿和小蓝/xx_文件名.jpg
角色:     小蓝（Sapphire）
出处:     《小绿和小蓝》· 笛子Ocarina
造型篇目: 机器人篇（程序员 / 蓝白卫衣）      ← 决定"这身衣服算不算数"
用途:     A / B / C                        ← 见第二节，决定我怎么处理
画面:     单人 / 双人 / 群像；有文字☑ 无文字☐；背景 干净 / 复杂 / 已透明
来源:     官方立绘 / 动画截图 / 漫画封面 / 同人（作者+链接）
授权:     可入库 / 仅本地自用             ← 决定能不能进 git、能不能随包分发
备注:     比如"这张的呆毛和卫衣最准，但手挡住了"
```

**这些栏位都是有用途的**，不是形式：

| 栏位 | 我拿它做什么 |
|---|---|
| 造型篇目 | `docs/xiaolan.md` 记着：机器人篇是卫衣/白大褂，魔王篇是盔甲翅膀。选错篇目整张图就白做 |
| 用途 A/B/C | 决定用"柔边蒙版化掉背景"还是"直接当透明素材"，两条路产出完全不同 |
| 画面（单人/文字/背景） | 单人 < 双人 < 群像越好裁；有标题文字的裁成圆形必带杂物（实测 02/04/16 就是这种） |
| 来源 / 授权 | 只本地自用 → 放 `_refs/`；可入库 → 才有资格进 `scripts/fixtures/` 或随包分发 |
| 备注 | 告诉我"哪张最准"，我就不用靠观感排序 |

## 二、三种用途，走三条不同的路

| 用途 | 含义 | 我怎么处理 | 产出 |
|---|---|---|---|
| **A. 直接素材** | 这张图本身就能当角色（最好是透明底、单人） | `--no-mask` 按 4:3 裁切重采样 | 可直接上传的角色 PNG |
| **B. 造型参考** | 只是告诉我"角色长这样/这身衣服" | 加**柔边蒙版**把背景化掉，做成头像式候选 | 圆形/椭圆头像 PNG（试验用） |
| **C. 动效或表情参考** | 用在程序化 SVG 上（呆毛怎么摆、表情怎么变） | 不转图，我按它调 `lib/client.js` 的 SVG 与动画 | 代码改动 + 预览截图 |

> 同一张图可以同时是 B 和 C。只标你确定的部分，剩下的我按默认处理并回报。

## 三、交付形式（哪种都行）

1. **表格**：按第一节的模板一行一张，贴给我 —— 最省事，我直接开工。
2. **文件 + 一句话**：把图丢进 `_refs/<作品名>/`，然后告诉我"这几张是小蓝机器人篇，03 那张最准"。
3. **只给链接**：我自己不去搜（搜出来的信息不准，这正是你在纠正的问题）；你给链接我就只按你给的那张办。

## 四、我会回报什么

每批素材我会给出：

- **对比图**：所有候选并排，标文件名与尺寸，方便你一眼挑（做法见 `scripts/make-pet-image.mjs` + 截图流程）
- **每张的体检结果**：画布比例、是否真有透明通道、体积是否在 1.5MB 内、透明区占比
- **入账**：把确认过的信息写进本文末尾的「已确认清单」，以后不再靠猜
- **接入**：`?art=` 试验 → 你点头后接进挂件；需要的话同步调整程序化 SVG

## 五、合格素材的红绿灯（供你收集时参考）

| 🟢 直接用 | 🟡 能救 | 🔴 别收集 |
|---|---|---|
| 透明底 PNG/GIF/WebP，单人 | 背景干净（纯色/渐变）的单人插画 | 群像、拼图 |
| 分辨率 ≥ 1024×768（4:3 母版） | 512×384 以上 | 带标题文字 / 水印 / logo |
| 主体占画布 78%–86%，四周留边 | 主体偏小（可重裁） | 主体被裁断（缺手缺脚） |
| 头朝左（或左右对称） | 头朝右（我会镜像，但文字会反） | 动态模糊 / 低分辨率放大件 |

> 舞台基准是 **224×168 = 4:3**，角色可放大到 160%，2× 屏下最坏要 **716×538** 物理像素。
> 所以母版建议 **1024×768**。完整规格见 [asset-checklist.md](asset-checklist.md) 2.2 / 2.3.1。

## 六、文件放哪

| 位置 | 放什么 | 是否入库 |
|---|---|---|
| `_refs/<作品名>/` | 你收集的原始参考图 | ❌ 不入库（`.gitignore`，且在理由里写明了是第三方参考） |
| `assets/` | 我转出来的试验品 | ❌ 不入库（同上） |
| `scripts/fixtures/` | 自检专用的**自绘**素材 | ✅ 入库（不含第三方美术） |
| 挂件运行时 | 右键「换个角色图」上传，存在 localStorage | 不进仓库 |
