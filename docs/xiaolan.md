### ⚠️ 关于「睿智的发明家」

官方设定里小蓝的职业是**程序员 / 工程师**，「发明家」那一面体现在**机器人篇** ——
他独自开发出了机器人小绿。这一点直接决定立绘选型：

| 篇目 | 小蓝的身份 | 造型 |
|---|---|---|
| **机器人篇** | 程序员 / 开发者 | **蓝白卫衣**（或白大褂）← 符合「发明家」 |
| 魔王篇 / 魔法篇 | 骑士、魔法世界角色 | 盔甲、翅膀、王冠 |
| 演员篇 | 演员 | 与小绿是恋人 |
| 回忆篇 | 能预见未来却记不住过去的超能力者 | — |
| 三分钟篇 | 与恶魔交易的吉他手 | — |

**要用「发明家」人设，就取机器人篇的卫衣造型**，别拿魔王篇/魔法篇的奇幻立绘 —— 那是完全不同的衣服。

## 二、⚠️ 图源陷阱：别搜「小蓝和小绿」

搜「小蓝和小绿」时，PNG 素材站排在最前面的结果其实是 **Pocoyo**（一部西班牙儿童动画），
和笛子Ocarina 的《小绿和小蓝》**毫无关系**。标签里会写「儿童动画 / 西班牙动画 / 教育节目」。
按那个做出来会是一个完全无关的蓝色小人。**正确顺序是「小绿和小蓝」**（小绿在前）。

## 四、出图方向建议（针对本挂件）

### 4.1 用卫衣版，不要用奇幻篇立绘

挂件最小时只有 **134×101 CSS px**。盔甲、翅膀、王冠缩到这个尺寸就是一团噪点。
**蓝发 + 呆毛 + 蓝白卫衣**在 20px 下依然可辨认 —— 这才是能用的角色剪影。

### 4.2 画半身或坐姿，不要站姿全身

舞台是 **224×168 的 4:3 横构图**，而小蓝是 178cm 的正常人体型。
站姿全身塞进 4:3 会严重浪费宽度（见 [asset-checklist.md](asset-checklist.md) 2.2）。

**推荐构图**：伏案对着笔记本的半身 —— 既贴合程序员人设，
又天然是横构图，还顺带解决了「手不知道放哪」的问题。

### 4.3 呆毛必须保留

呆毛是他最好认的剪影特征，而且**是唯一能动的部件**：
呆毛晃动可以直接当待机动画，对应现有 SVG 架构里 `.hf-tail`（尾鳍摆动）那一类部件级动画。
（默认形象里这套动画挂在鱼鳍上，换成小蓝后建议挂到呆毛上。）

### 4.4 可选小道具

笔记本 / 机械键盘 / 咖啡杯 / 扳手，做成独立图层可以参与动画。
但注意别堆太多 —— 挂件本体只有 224×168。

## 五、三条产出路线

| 路线 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 程序化 SVG**（✅ **已实现**） | 手写小蓝的 SVG，替换 `lib/client.js` 里的角色定义 | 部件级动画最全、零素材依赖、零体积、零外部版权风险，和现有架构完全一致 | 造型是几何化卡通，不是原作画风 |
| **B. AI 生图** | 用 [character-spec.md](character-spec.md) 的提示词框架，角色描述换成小蓝；构图改成 4:3 半身坐姿；把 `02` 号图喂给支持参考图的模型 | 快，质感好 | 需要抠图后处理；呆毛/发色容易跑偏；要受 1.5MB 上限约束 |
| **C. 手工抠图** | 从官方立绘抠背景 | 保真度最高 | 站姿全身塞 4:3 仍需重新构图；工作量大 |

### A 路线已落地的部件与动画

`lib/client.js` 的 `xiaolanSVG()` 就是角色定义。可动部件全部带类名，动画在 CSS 里：

| 类名 | 部件 | 动作 |
|---|---|---|
| `.hf-bob` | 整体浮动容器 | 上下浮 7px |
| `.xl-ahoge` | **呆毛** | 左右摆动（标志性待机动作） |
| `.xl-arm-l` / `.xl-arm-r` | 左右手臂 | 轻微反向晃 |
| `.xl-torso` | 躯干 | 呼吸缩放 |
| `.hf-eye` | 眼睛（左右各一组） | 定时眨眼 |
| `.hf-shadow` | 地面投影 | 随浮动明暗 + 横向缩放 |
| `.hf-bubbles` | 头顶右侧的「灵感火花」 | 点击时冒 5 个，向上飘散 |

配色改 `<defs>` 里五个渐变即可；把 `xl-hoodie` 调白、`xl-hood` 调浅就得到**白大褂（发明家）版**。

**已验证**：`node scripts/check.mjs` 14 项全过；用 headless Chrome 渲染 `preview.html`
在 448×336 / 224×168 / 134×101 三档尺寸下核对过外观，贴左侧镜像与设置菜单均正常。

### 想换成火柴人原作风？—— ✅ **已实现，而且用的是作者原图**

原作（单行本封面）本身是刻意的**火柴人**画风 —— 圆头、点眼、彩色上衣（小蓝=蓝，小绿=绿）。
现在挂件里的「**作者原画·简笔**」这一档就是**作者本人的火柴人**（`scripts/cutout-pet.mjs`
从他的漫画格子里抠出，气泡/文字/桌面线用 `--main` 自动去掉），按状态换图：
常态＝莞尔一笑、被点＝害羞、拖动＝撒娇・奋力一甩、落手＝吃惊、结束＝宕机、工作＝认真工作。

> 早期我还手画过一版简笔画 SVG（`xiaolanSimpleSVG()`），用户评价"还是你仿着画的" ——
> 于是改回**直接用原图**。手画那版现在只当**没素材时的兜底**（全新克隆里 `assets/` 是空的）。
> 详见 [architecture.md](architecture.md) §6.3 / §6.8 / §6.9。

## 六、台词是怎么定的

`lib/client.js` 的 `LINES` 六池已按小蓝的性格重写：

| 池子 | 触发时机 | 语气定位 |
|---|---|---|
| `greet` | 启动后首次出现 | 冷淡但友好，话短 |
| `click` | 左键点他 | 被关注时的窘迫感 |
| `drag` | 拖动中 | 技术宅的即时反应（拿参数说事） |
| `drop` | 松手落位 | 极简确认 |
| `turnEnd` | 一轮对话结束 | **提到工作就认真**——用工程语汇表达完成 |
| `idle` | 空闲随机 | 自言自语，暴露「电脑比人好懂」的世界观 |

**说明：这些是我按上述性格原创的台词，不是从原作摘录的句子。**
我没有伪造「原作原句」—— 无法核实来源的假引文，比诚实的原创更糟。

**如果你手上有喜欢的原作台词**，直接贴给我，我按上面六个池子归类插进去。
插入时注意两点：
1. 气泡最宽 `min(230px, 58vw)`，单条**尽量 ≤ 12 字**，否则会换行撑高气泡
2. 同一池子内避免连续两条语义重复（`pick()` 只保证同类不连续重复，不做语义去重）
