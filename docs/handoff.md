## 铁律（违反任一条都会出真事故）

| # | 规则 | 为什么 |
|---|---|---|
| 1 | `lib/client.js` **必须是经典脚本**（不许出现 `import` / `export`） | 它由 `window.__ModuleLoader__.load({factory})` 载入；一旦用了 ESM 语法，**整个挂件加载失败**。`check.mjs` 用 `vm.Script` 验这一条 |
| 2 | **不许改**包名 `dsh-handsome-fish` 与 CSS 前缀 | 会断开 profile 里的 `link:` 安装，并让用户已存的 localStorage 全部失效 |
| 3 | **第三方美术绝不入库** | `assets/`、`_refs/` 已在 `.gitignore`。角色原画只在本机；公开发布前需用户自行确认授权 |
| 4 | 改完**必须跑两套自检** | 这是唯一能挡住"删多了 / 接线断了"的东西 —— `node --check` 只查语法，**抓不到逻辑删多**（真发生过：一次误删把 `apply()` 搞崩，而语法检查是绿的） |
| 5 | 抠简笔素材**必须带 `--close 14`** | 头部轮廓有缺口时，flood fill 会漏进脑袋、`--main` 再把眼睛当孤立小块丢掉 →「白圈没有脸」。**已犯两次** |
| 6 | 抠图结果**必须在浅色底上核对** | 深色底上黑描边与背景同色，"描边被吃掉"会被误判成正常 |
| 7 | **不要用 PowerShell 往返改 UTF-8 源文件** | `Get-Content -Raw` + `Set-Content` 会把中文按 GBK 读再写回，整份文件变乱码（真发生过，已从 git 恢复）；顺带还会加 BOM |
| 8 | 注意"嵌套语法" | `scripts/cutout-pet.mjs` 的页面代码在**模板字符串**里 → 注释里不能出现反引号；块注释里不能出现 `*/`。两个都踩过 |
| 9 | 改文件前先读它 | 工具要求"先读再改"；文件被脚本改过之后必须重读 |
| 10 | 加了功能就**加断言** | 本项目查出来的 bug 几乎都是自检先发现的；"监听没接上"这类只有**真点击**才发现 |
