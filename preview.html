右下角应该是小蓝

预览 / 调试台

这个页面不依赖 DSH 宿主，直接以「经典脚本」方式加载 lib/client.js，并给它一个最小的 __ModuleLoader__ 与 ctx 桩，用来在浏览器里肉眼检查角色外观、动画与交互。
也可以在右下角那个小蓝身上：左键拖动（松手吸附到最近一侧）、左键点一下、右键打开设置菜单。

调试入口

window.__HANDSOME_FISH__ 暴露了 state / say() / hide() / show() / menu() / sound(name) / reset() / destroy()。 偏好存在 localStorage["dsh-handsome-fish:v1"]。
